# 1. ภาพรวมระบบ (System Overview)

## 1.1 วัตถุประสงค์

ระบบ Inventory Stock Management ถูกพัฒนาขึ้นเพื่อใช้บริหารจัดการวัตถุดิบของร้าน Sushi Hana Thailand โดยมีเป้าหมายในการควบคุมสต็อกให้ถูกต้อง ลดความสูญเสีย และสามารถวิเคราะห์การใช้วัตถุดิบของแต่ละสาขาได้แบบ Real-time

ระบบจะช่วยลดการใช้ Excel และการคำนวณด้วยมือ พร้อมจัดเก็บข้อมูลทั้งหมดไว้บนฐานข้อมูลกลาง (Supabase)

---

## 1.2 ปัญหาของระบบเดิม

ปัจจุบันการจัดการสต็อกมีข้อจำกัดหลายด้าน ได้แก่

- คำนวณการใช้วัตถุดิบด้วยมือ
- ข้อมูลกระจายหลายไฟล์ Excel
- ตรวจสอบย้อนหลังได้ยาก
- ไม่มีระบบติดตาม Lot และวันหมดอายุ
- ไม่สามารถดูข้อมูลหลายสาขาพร้อมกัน
- ไม่มีประวัติการแก้ไขข้อมูล (Audit Log)

---

## 1.3 เป้าหมายของระบบใหม่

ระบบใหม่ต้องสามารถ

- คำนวณยอดการใช้วัตถุดิบอัตโนมัติ
- รองรับการทำงานหลายสาขา
- จัดการวัตถุดิบตามหลัก FIFO
- แจ้งเตือนวัตถุดิบใกล้หมดอายุ
- บันทึกประวัติการทำรายการทุกขั้นตอน
- แสดง Dashboard และรายงานแบบ Real-time
- รองรับการขยายระบบในอนาคต

---

# 2. ขอบเขตของระบบ (System Scope)

ระบบครอบคลุมการทำงานตั้งแต่การรับสินค้า จนถึงการวิเคราะห์การใช้วัตถุดิบ

ประกอบด้วย

- Master Data
- Beginning Stock
- Purchase / Receiving
- Stock Count
- Inventory Analysis
- Dashboard
- History / Audit Log
- Import / Export
- Multi Branch

---

# 3. โครงสร้างระบบ (System Modules)

## 3.1 Dashboard

หน้าสรุปข้อมูลสำหรับผู้บริหาร

แสดง

- มูลค่าสต็อกรวม
- จำนวนวัตถุดิบ
- สินค้าใกล้หมดอายุ
- สินค้าหมดอายุ
- สินค้าสต็อกต่ำ
- สรุปการรับสินค้า
- สรุปการใช้วัตถุดิบ

สามารถเลือก

- ทุกสาขา
- รายสาขา

---

## 3.2 Master Data

ใช้จัดการข้อมูลพื้นฐานของระบบ

ประกอบด้วย

- วัตถุดิบ
- Supplier
- Category
- Unit
- Branch

---

## 3.3 Beginning Stock

ใช้กำหนดสต็อกเริ่มต้น

กรอกเพียงครั้งแรก

หลังจากนั้นระบบจะสร้างให้อัตโนมัติจากผลการตรวจนับครั้งล่าสุด

---

## 3.4 Purchase / Receiving

ใช้บันทึกการรับสินค้า

สามารถ

- ค้นหาจากรหัส
- ค้นหาจากชื่อ
- Filter ตาม Supplier
- Filter ตาม Category

กรอกข้อมูล

- จำนวน
- ราคา
- วันหมดอายุ
- หมายเหตุ

ระบบสร้าง Lot Number อัตโนมัติ

---

## 3.5 Stock Count

ใช้ตรวจนับสต็อกคงเหลือ

รองรับ

- ค้นหา
- Filter
- หลายสาขา

ผู้ใช้กรอกเฉพาะ

จำนวนคงเหลือจริง

ระบบนำไปคำนวณการใช้วัตถุดิบอัตโนมัติ

---

## 3.6 Inventory Analysis

ใช้วิเคราะห์การใช้วัตถุดิบ

เลือก

- สาขา
- ช่วงเวลา

ระบบคำนวณ

```
Beginning Stock

+

Purchases

-

Ending Count

=

Usage
```

---

## 3.7 History / Audit Log

เก็บประวัติการทำรายการทั้งหมด

สามารถค้นหา

Export Excel

ตรวจสอบย้อนหลังได้

---

# 4. สูตรการคำนวณ (Business Logic)

## สูตรหลัก

```
ยอดใช้

=

สต็อกต้นงวด

+

รับเข้า

-

สต็อกปลายงวด
```

---

## สต็อกต้นงวด

หลังจากเริ่มใช้งานระบบ

จะคำนวณอัตโนมัติ

```
Beginning Stock

=

Ending Count ของงวดก่อน
```

ไม่ต้องกรอกใหม่

---

## รองรับทุกช่วงเวลา

- 3 วัน
- 5 วัน
- 7 วัน
- รายเดือน
- Custom

ระบบจะเลือก Stock Count ล่าสุดก่อนวันเริ่มต้นของช่วงที่เลือกมาเป็น Beginning Stock โดยอัตโนมัติ
